# Mashiel Khan — Portfolio

This is a personal portfolio website showcasing projects and skills.

Features
- Responsive, accessible single-page site
- Projects, skills, contact form (demo)
- Clean modern UI with dark theme

How to run locally
1. Clone the repo: git clone <your-repo-url>
2. Open `portfolio.html` in a browser (or serve with a static server):
   - Windows PowerShell: Start-Process "portfolio.html"
   - Or use `npx serve` / `python -m http.server` for a local server

Deploy
- Deploy to GitHub Pages by pushing `portfolio.html` to the `gh-pages` branch or enabling Pages from the repository settings.
- Or deploy to Vercel/Netlify for automatic builds.
